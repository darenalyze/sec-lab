## Educational Disclaimer

This documentation is strictly created for educational, research, and defensive security purposes. All activities and demonstrations were conducted in a controlled, isolated local lab environment with full authorization.

Do not attempt any techniques demonstrated here on networks or devices you do not own or have explicit written permission to test. Unauthorized access or system testing is illegal.

## Purpose

To demonstrate my passion, practical knowledge, and technical documentation skills in cybersecurity. 

This repository highlights both offensive and defensive methodologies:
* **Offensive (Red Team):** Documents how security vulnerabilities are identified and exploited in an isolated test environment.
* **Defensive (Blue Team):** Explains the exact steps taken to remediate vulnerabilities, apply security patches, and harden systems against attacks.
